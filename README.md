# 🌦️ WeatherNow

A simple weather app built using **HTML, Tailwind CSS, and JavaScript**.

## Project workflow (`context/`)

Kaam **screenshot wale pattern** ke saath organize hai: notes, plans, aur decisions `context/` ke folders mein — har folder ka matlab `context/README.md` mein likha hai. Naya kaam shuru karte waqt wahan dekho / chhota note daalo.

## Pages in this repo

| File | Purpose |
|------|---------|
| `Weather.html` | Weather app (OpenWeather API) |
| `Todo.html` | Tasks + `localStorage` |
| `bakery/Bakery.html` | Bakery landing page (demo content; Tailwind: `../src/output.css`) |

## Features

- Search weather by city
- Real-time temperature
- Humidity, wind & pressure
- Hourly forecast
- Saves last searched city
- Responsive modern UI

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- OpenWeather API

## How to Use

1. Enter city name
2. Press search
3. View live weather details
